## Step 7 — The Fairfax Daily Scoop (one-page printable newspaper), then print it
**Publishing schedule (scoop/README.md):** Monday–Friday daily edition; **Saturday Weekend Edition** covering Saturday and Sunday; **Sunday: skip Step 7 entirely** (no build, no print, no log) and say so in one line of the run report. Use today's America/New_York weekday.

Run this AFTER Step 6, even if an earlier step had a problem (a failed send or skipped Step 6 does not cancel the newspaper; just note it). It reuses the calendar and email data already gathered above — do not re-query Outlook. Every edition is a fresh one-page Letter PDF built from the build kit in `scoop/`.

**7a — Get the kit.** Copy `scoop/` to a fresh working directory (e.g. `cp -r scoop /tmp/scoop-$(date +%F)` and work there, so the repo copy stays clean). It holds build2.py, art.py, render.py, setup.sh, edition.json (a sample — use it only as the schema and style example) and README.md. hedcut.py is RETIRED; never import or edit it. The logs live in the repo at `logs/riddle-log.md` and `logs/content-log.md`; read both before writing content and never repeat anything in them.

**`scoop/README.md` is authoritative.** Its NEW STANDING RULES (Oct 8, 2026), NEVER REPEAT rules (Oct 7) and Standing requests (4-day forecast, unconfirmed = silent, real photo or nothing, Word of the Day, Thursday bagel note, fantasy football, Tech Corner on Wed/Sat, Cutest Critter on Tue/Fri) override anything below that conflicts. Read README.md first: it holds the build commands, the edition.json field list and the approved layout rules. Then run `sh setup.sh`. Never run `playwright install` (Chromium is preinstalled).

**7a-ii — Today's state.** The kids' team boxes (`mda`, `spartans`), Ari's fantasy box and the banner are copied from `state/<today>.json`. If that file does not exist yet, run `./fo collect` in the repo now (it writes it; never hand-write these boxes). Copy `state.mda`, `state.spartans` and `state.ari_fantasy` verbatim into edition.json (omit a box whose value is null; `ari_fantasy` is null except Mon, Tue, Thu and Sat during the NFL season).

**7b — Gather content for TODAY (America/New_York date).**
- *Family schedule* (`sched`): today's items only, in time order, from the digest's calendar and email data (Elle, Ari, Family, PlayMetrics, etc.), same kid/location rules as the digest. Do not mention kids' sports anywhere except in this schedule and the kids' team boxes (7a-ii) — plus, when a kid has a game this evening, also add it as one bullet under "Tonight in Detroit" (`tonight`) in the form "<b>Name's game</b>, time, place". `week` ("Coming Up") = the next ~5 days from the same data, short. `quarton` = the few most useful school notes still live from the digest (picture day, form due dates, sign-ups).
- *Weather*: WebFetch https://forecast.weather.gov/MapClick.php?lat=42.523705&lon=-83.230349&unit=0&lg=english&FcstType=text&TextType=1 for `hi`, `wx` (today) and `wx2` (tonight and tomorrow); credit NWS in the footer only (`foot`), never in the weather text.
- *Lunch* (`lunch`): today's entry from the Quarton lunch-menu PDF already fetched in the digest (match on the day number; the extracted weekday labels can be wrong; Wednesday is pizza day). On days with no school or no menu, say so.
- *Sports* — previous day's results (`yday`): NFL (any games played the previous day), NBA, NHL, MLB as in season, from CBS Sports scoreboard pages or NFL.com / NHL.com. `lions`: a short Lions report (last result and next game, nfl.com Lions schedule). `tonight`: today's Detroit games — Red Wings (nhl.com schedule), Tigers, Lions, Pistons — one bullet each, or "No game." Seaholm & Groves (`hs`, 3 short bullets): latest results and next games for football and tennis (and soccer or other fall sports if posted) from maxpreps.com pages: Seaholm https://www.maxpreps.com/mi/birmingham/seaholm-maples/football/ and /volleyball/ ; Groves https://www.maxpreps.com/mi/beverly-hills/groves-falcons/football/schedule/ and /volleyball/schedule/. If a page is stale or missing, say "latest result not posted" rather than guessing.
- *Stories* (only fun, kid-friendly): `head`, `sub`, `story` (3 paragraphs, ~200 words), `head_src` = headline story; plus `news[0..2]`, each [headline, 60–110 words, source]. Search order: a fun Birmingham, MI story first (Hoodline, Patch, city or BPS news); if none, a Detroit/Michigan story (zoo, museum, science, kids events); if none, anywhere (Science News Explores, NASA APOD, etc.). Never use sad, scary, political or crime news. Summarize in your own words; keep each source in its field for the log and credit the outlets in `foot`, never as a line on the page (scoop/README.md); do not copy articles. Avoid repeating a story from recent editions if you can tell.
- *Photo*: real photo or nothing (README New Standing Rule 3). Never draw, generate or stipple a headline illustration.
- *Comic*: write a new, original 4-panel gag each day for ARTIC, BIG BEAR & FRIENDS (Artic, Big Bear, Mackenzie the mini-poodle, Uni the unicorn, Bob the toy brick guy) as edition.json `comic`, composed from the art.py character library (scoop/README.md, Comic: Character Library; `python art.py --list`). Set most panels on a painted backdrop (README: Comic: painted backdrops) and log each panel's backdrop. Do not edit art.py or call backdrops.py. The cast prints from the painted character library automatically; never call Grok for the comic. Keep each bubble to ~2 short lines and fix every `COMIC WARNING` build2.py prints. Never draw or imitate Calvin and Hobbes, Peanuts or any other real strip or character.
- *Joke* (`joke`): read `logs/riddle-log.md` and write a NEW kid-friendly joke with punchline that repeats nothing in the log. No riddle in any edition (Jacob, 2026-10-10).
- *Banner* (`banner`): holidays from `state.almanac`, and on Fridays only, Shabbat with the sunset time, per the Design & Content Updates in scoop/README.md.
- *Layout* (`layout`, optional): arrange columns and sections so the day's content reads well (README: flexible layout).
- `date` and `foot` (sources line): update; keep the masthead and footer wording "The Fairfax Daily Scoop · Printed at the Shapiro house".

**7c — Build and check.** Write edition.json. Then `FONTDIR=./fonts $REPO/.venv/bin/python build2.py && $REPO/.venv/bin/python render.py newspaper.pdf`, where `$REPO` is the family-ops checkout (run `sh $REPO/scripts/bootstrap.sh` first if `.venv` is missing; never use the system `python3`, which can lack packages). render.py prints one "content bottom / column bottom" pair per column, then a `LAYOUT:` line. It must say `LAYOUT: OK`: every column filled to within 0–40 px of its bottom, with nothing spilling over (scoop/README.md, Full columns). If a column is `UNDERFILLED`, add `extras` (fun facts, history, a quote, an activity idea; never a drawing activity) and tune their text length or the column widths to close the last gap. If it is `OVERFLOW`, shorten text or rearrange `layout`. Never shrink fonts. Rebuild until OK. `pdfinfo newspaper.pdf | grep Pages` must say exactly 1 page. Convert to PNG (`pdftoppm -r 100 -png newspaper.pdf paper`) and Read it to check nothing is clipped or overlapping and that comic speech bubbles sit clear of the characters' faces. Fix and rebuild until clean. A `COMIC WARNING` that a character is drawn, not painted, means its pose, face, gear or prop is not in the painted library: pick one that is.

**7d — Log the joke, word and content.** Append one line "YYYY-MM-DD | joke | word" to `logs/riddle-log.md`, and append today's entry to `logs/content-log.md` in its existing format (headline, news items, tech story, headline photo credit or "no photo", comic gag + art description, critter). Do this once the PDF is final, before printing. **Archive the edition** (Jacob, 2026-10-11): copy the final PDF to `$REPO/editions/YYYY-MM-DD.pdf` (today's America/New_York date; the Weekend Edition is saved under Saturday's date). After printing (7e), commit both log changes and the edition PDF and push to `main` (`git pull --rebase origin main` first). Archive and commit even if printing failed; the digest email links to this file. Never in SHADOW mode (no commits).

**7e — Print it.** The PDF must be named exactly `newspaper.pdf` in the current directory. `RELAY_TOKEN` comes from the environment (set in the cloud environment's settings, never in this repo). Then run exactly:
`curl -sS -X POST ${RELAY_TOKEN:+-H "Authorization: Bearer $RELAY_TOKEN"} -H "Content-Type: application/pdf" --data-binary @newspaper.pdf "https://print.jacobshapiro.net/print?name=daily-$(date +%F).pdf"`
(If `RELAY_TOKEN` is unset, the token may be stored as an environment network secret for print.jacobshapiro.net, which the agent proxy attaches on its own; send the request without the header and judge success only by the reply.)
A reply containing `"status": "queued"` means it is printing. `"status": "duplicate"` means this exact PDF was already printed (the relay matches by sha256), so nothing printed again: that is fine, say so in the report, and never add `&force=1` unless Jacob asks for a reprint. Errors: 401 = token missing or wrong, 400 = not a PDF or a bad option, 502 = printer/CUPS problem. On any failure, check `curl -sS -m 15 https://print.jacobshapiro.net/health` (no auth); if it does not answer, report "print relay offline" (the Mac mini must be on and awake) and do not try another route. Relay defaults: Letter, color, double-sided, 1 copy (relay details from the Mac mini printing session, 2026-10-11). Never echo, print or log $RELAY_TOKEN and never write it into any file. If the request is blocked or times out, or the reply does not say queued (for example an error status or an auth failure), retry at most once, then push-notify Jacob (PushNotification) with the exact error and that today's paper did NOT print. Also deliver the PDF with SendUserFile either way so a copy exists in the session. Do not email the PDF (the mail tool cannot attach files).
